## 技术要点与坑（已验证）

1. **目标地址视频源是 HLS m3u8 流**，非完整 mp4。页面 `<video>` 用 blob；网络层捕获到 `surrit.com/<uuid>/playlist.m3u8`。部分地址的 mp4 是 HLS init 段（无帧数据），不能直接抓取。
2. **ffmpeg 抓 HLS 必须带 `-headers "Referer: <页面域名>"`**，否则 CDN 拒绝、输出空文件。这是能否抓帧成功的关键。
3. 早期批量并发请求触发 Cloudflare 风控（返回"请稍候…"），**逐个、放慢节奏处理即可通过**。
4. build_index 的 `--frames` 需指向"含视频子目录的父目录"，单个帧目录会被误判为 0 视频。
