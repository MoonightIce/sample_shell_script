# 流程与验收

已确认的状态路径：主页 → 我的 → 畅享中 → 升级无损音质/看视频续 VIP → 广告立即下载 → 内置网页或应用商店详情面板 → 停留至少 15 秒 → 左上关闭 → 回到广告，确认恭喜已获得奖励 → 右上关闭 → 继续奖励弹窗 → 回读剩余天数。

续领文案包含“再看1个，浏览5秒”“浏览5秒，马上领取”“看视频领取”“立即领取”，以及“再看N个广告/视频领第N日VIP”。它们是奖励弹窗，不按运营弹窗关闭。每天奖励完成后关闭面板并回读主页面，不能用商家落地页的“恭喜获得”冒充会员成功。

运营弹窗目前验证过全图会员领取、生日促销、打开通知。优先定位右侧小型关闭图标；初始“看广告拿VIP”的另一种弹窗尚未实际出现并验证。广告模板验证过拼多多和抖音；新布局需要先检查截图。不得点击取得、安装、购买或支付。

`run.py` 使用快照中的 label 与 identifier，并过滤零宽字符和部分离屏节点。固定坐标仅适用于本机 390×844 点布局。若跳出波点 App，脚本停止，交由操作者检查；不自动操作任意第三方 App。

证据保存在 Skill 的 runs/ 下。成功目录有 target-days.png、snapshot.json、my.png、result.json；result.json 中 observed_days 是主页面回读，returned_to_my 是返回核实结果。失败保留 stopped.png（截图失败时可能没有文件）。
